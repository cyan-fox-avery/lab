# Rock Go Crunch — v2

Mobile-first GitHub Pages prototype for a gemstone / geology collecting incremental game.

## v2 features

- Fixed 10×10 mine grid with no coloured proximity hints
- Isolated finds, small veins, and large veins
- Two depths
- Quartz, amethyst, hematite, chalcopyrite, garnet, topaz, and pyrite
- Rare trilobite fossils and historical mining tags
- Surveying upgrades that report veins and later react to unusual finds
- Free processing: raw → tumbled → cut for gems, ore → refined metal for ores
- Precision Workshop upgrade for later gem processing
- Collapsible Workbench cards with lifetime stats
- Museum wings for Minerals, Ores & Metals, Fossils, and History
- Multi-track upgrade shop with balance always visible
- Currency stored in cents and displayed as 47¢ below one dollar, then $1.00, $1.01, etc.
- Local browser save
- No external libraries or assets
- No real-money purchases, energy timers, or premium currency

## GitHub Pages

Replace the repository contents with these four files:

- `index.html`
- `style.css`
- `script.js`
- `README.md`

Publish GitHub Pages from the repository root. No build step is required.

## Save key

`rock-go-crunch-v2`
